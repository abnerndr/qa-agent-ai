# Option Matrix — Adoção do Work OS

| Opção | Esforço | Risco | Reversibilidade |
|---|---|---|---|
| Adotar a estrutura completa (10 camadas) | Médio (uma sessão) | Baixo | Alta — é só arquivos e pastas |
| Pasta mínima (só README + CLAUDE.md) | Baixo | Médio — sem histórico de decisão nem controle de fonte | Alta |
| Sem estrutura, seguir como está | Nenhum | Alto — retrabalho e perda de contexto a cada sessão | N/A |

**Escolhida:** estrutura completa — é a única opção que entrega registro de decisão, controle de confiança de fonte e travas automáticas desde o primeiro dia.
