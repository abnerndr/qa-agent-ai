# Runbook — Como registrar uma decisão

Procedimento para toda decisão nova, grande ou pequena.

1. Escrever ou atualizar `docs/problem-brief.md` com o objetivo em uma frase.
2. Listar as alternativas em `docs/option-matrix.md` (esforço, risco, reversibilidade).
3. Registrar a escolha em uma linha de `docs/decision-log.md`.
4. Se a decisão muda a estrutura ou forma de trabalho do projeto (não é só o dia a dia), criar um ADR em `.claude/adr/` seguindo o formato de `adr-001-adocao-do-work-os.md`, e registrar no índice `.claude/memory/adr-index.md`.
5. Se algo aprendido nesse processo deve valer para o futuro, salvar em `.claude/memory/` (ver seção de memória do CLAUDE.md).
